# Soudeur — Horaires

Web app mobile-first pour le **groupe soudeur**.

## Lancer

```bash
cd soudeur-horaires
python3 -m http.server 8765
```

Ouvre `http://127.0.0.1:8765/` sur ton téléphone ou navigateur.

## En ligne

https://leoacqueberge.github.io/soudeur-horaires/

## Fonctions

- Liste des créneaux Soudeur
- Toggle **Sans nocturne** / **Avec nocturne**
- Carte « Prochain » selon l’heure actuelle
- Police TikTok Sans
