# Soudeur — Horaires Stomp

Web app mobile-first pour le **groupe soudeur** (modules **Stomp**).

## Lancer

```bash
cd soudeur-horaires
python3 -m http.server 8765
```

Ouvre `http://127.0.0.1:8765/` sur ton téléphone ou navigateur.

## Fonctions

- Liste des créneaux Stomp
- Toggle **Sans nocturne** / **Avec nocturne**
- Carte « Prochain » selon l’heure actuelle
- Police TikTok Sans
